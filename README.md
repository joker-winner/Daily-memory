# 日常 · 个人工作生活工作台

一个供个人在本机使用的工作与生活记录应用。它把每日安排、恋爱日常、工作、健身、饮食和娱乐记录放在一个页面中，方便按日期查看和维护。应用不需要登录，数据保存在当前浏览器的本地存储中。

## 主要功能

- **首页总览**：查看当天安排、完成进度和各模块摘要；提供沉浸学习入口。
- **今日计划**：按日期汇总来自各模块的日记、纪念日、约会、工作、训练、餐食和娱乐事项；支持新增、编辑、删除及可完成状态事项的勾选。
- **恋爱日常**：分别记录日记、纪念日和约会安排；提供可添加和切换本地照片的相册。
- **工作计划**：按周浏览日期，以任务时间线管理工作事项、截止日期、优先级（低、中、高、紧急）、状态和备注。
- **健身计划**：按锻炼部位记录动作、次数和体重；内置动作目录，按目标热量生成训练建议，并估算训练消耗。
- **饮食计划**：按日期与餐次记录食物和重量；内置食物目录，支持自定义食物热量并即时估算摄入；可按目标热量生成包含多餐和营养信息的建议。
- **游戏娱乐**：以活动卡片记录安排、时长和感受，活动图标会依据名称匹配。
- **数据与设置**：导出完整 JSON 备份、从有效备份恢复或清空本机数据。

## 安装与启动

### 环境要求

- Node.js 18 或更新版本
- 现代桌面浏览器

项目没有 npm 运行时依赖，不需要执行 `npm install`。

### 启动

在项目根目录运行：

```sh
node server.js
```

在浏览器打开 <http://127.0.0.1:4173/>。保持终端中的服务运行；要停止时按 `Ctrl+C`。

必须使用同一台电脑、同一浏览器和同一个网址访问，才能读取同一份浏览器本地数据。更换浏览器、清理该网站数据或改用不同网址（例如不同端口）时，浏览器可能会显示一份新的空数据。

## 使用方法

1. 从左侧导航进入模块。
2. 使用“新增”入口创建记录，按表单填写日期、名称和相应信息并保存。
3. 健身和饮食页面可选择日期查看记录；日历可展开后切换月份或选择具体日期。
4. 今日计划会汇总选定日期中可同步的模块记录。某些记录（如训练或餐食）提供实际/完成状态时，可在今日计划中更新状态。
5. 在“数据与设置”选择导出备份；恢复时选择之前导出的 JSON 文件。恢复会覆盖当前本地数据，并在确认后执行。

## 输入与输出示例

### 记录一餐

输入：

```text
日期：2026-11-11
餐次：午餐
食物：鸡胸肉
重量：200 克
```

输出：页面显示估算热量 **330 千卡**（使用内置食物目录中的常见估算值），并将该条餐食保存在本机浏览器中；它也会出现在对应日期的饮食记录和今日计划汇总中。

### 记录工作事项

输入：

```text
事项：完成周报
截止日期：2026-11-12
优先级：高
状态：待办
```

输出：工作计划的对应日期时间线显示“完成周报”，并标注“高”优先级和“待办”状态；该事项也可在今日计划中按日期查看。

### 导出备份

操作：在“数据与设置”点击“导出数据备份”。

输出：下载一个 JSON 文件，包含应用支持的记录集合、设置和相册数据，可用于之后恢复。

## 数据与隐私

- 记录写入当前浏览器来源下的 `localStorage`；照片缩放压缩后以本地数据形式保存。
- 本应用没有账号、云数据库或联网同步功能。备份文件由用户自行保存和管理。
- 清除浏览器网站数据会删除该浏览器中保存的记录；请定期导出备份。
